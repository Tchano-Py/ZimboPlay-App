# Zimbo-play App

Este repositório contém o desenvolvimento do aplicativo "Zimbo-play" para a TV Zimbo, uma cadeia televisiva angolana. O layout do aplicativo foi cuidadosamente desenhado no Figma pelo talentoso designer António Dombaxe e está sendo construído utilizando o framework Flutter.

### Objetivo

O objetivo deste projeto é fornecer uma plataforma móvel intuitiva e amigável para os usuários assistirem ao conteúdo da TV Zimbo, melhorando a experiência de visualização através de um design moderno e funcionalidades robustas.

### Tecnologias Utilizadas

- **Figma**: Para o design do layout do aplicativo.
- **Flutter**: Para o desenvolvimento da aplicação.

### Testes e Compatibilidade

A aplicação foi testada apenas em plataformas Android. Devido à falta de acesso a um dispositivo iOS, não foi possível testar a aplicação em iPhones.
